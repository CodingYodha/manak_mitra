##  Executive Summary

Navigating India's **Quality Control Orders (QCOs)**, **Indian Standards (IS)**, and BIS certification schemes (**ISI**, **CRS**, **FMCS**, **Hallmarking**) is traditionally complex, fragmented, and intimidating for Micro, Small & Medium Enterprises (MSMEs), foreign manufacturers, and everyday consumers.

**Manak Mitra** is an authoritative, multi-channel, multilingual compliance assistant engineered with a **zero-hallucination** architecture. Unlike generic conversational bots that invent standard numbers when uncertain, Manak Mitra couples deterministic SQL queries and multilingual dense retrieval with strict guardrails: **it refuses to answer when official data is absent** and directs users to the official BIS helpline.

---

##  Key Features

- ** Verified Mandate & Standards Discovery**
  - Instant lookups for products and HSN codes against notified QCOs and Indian Standards.
  - Zero-model pure-SQL path for mandate verification backed by official e-Gazette notifications.
- ** Strict Guardrails & Abstention Gate**
  - Regex-based IS-number enforcer removes any unverified standard numbers generated by LLMs.
  - Automatic abstention when similarity falls below confidence thresholds (`FLOOR = 0.35`), providing the official BIS National Toll-Free Helpline (`1800-11-4000`).
- ** One-Page Compliance Passport**
  - Generates a complete, single-page printable compliance dossier for any product.
  - Combines governing QCO, IS status, testing requirements, recognized laboratories, indicative fees, and step-by-step audit timelines.
- ** Multilingual & Voice Enabled**
  - Native Hindi and English support using `paraphrase-multilingual-MiniLM-L12-v2`.
  - Browser-based speech recognition and Bhashini ULCA API integration for vernacular speech interactions.
- ** Mark Structural Verification (OCR)**
  - Tesseract OCR structural validator for Hallmarking (HUID + purity codes), ISI licence numbers (`CM/L-xxxxxxx`), and CRS registration numbers (`R-xxxxxxxx`).
  - Catches structural counterfeits without claiming live closed-loop government API access.
- ** Multi-Channel Delivery**
  - Interactive Web UI (React + Vite + Leaflet Maps + Force-Directed Knowledge Graph).
  - Headless WhatsApp Bot (via Baileys transport).
- ** Ministry Intelligence Dashboard**
  - Real-time visibility into query volume, regional and linguistic distribution, high-demand product sectors, and **unanswered/abstained questions** to highlight gaps in published regulatory information.

##  The Core Demo Specification (`DEMO.md`)

Manak Mitra is anchored around three benchmark products across the primary BIS certification schemes:

| Product | Scheme | Applicable Standard / Rule | Verification Type |
|---|---|---|---|
| **9 W LED Bulb** | Compulsory Registration Scheme (CRS) | **IS 16102 (Part 1)** | Mandatory Safety & Performance |
| **22K Gold Ring** | Hallmarking & HUID | **IS 1417** (Purity: 916) | 6-digit Alphanumeric HUID |
| **Children's Plastic Toy** | ISI Scheme (Scheme-I) | **IS 9873 (Part 1)** | Mandatory Quality & Safety Mark |

### The Six Demo Beats
1. **Visual Knowledge Graph**: Force-directed interactive network rendered on-screen before spoken presentation.
2. **Vernacular Voice Query**: Voice question asked in Hindi (*"क्या मुझे LED बल्ब के लिए BIS चाहिए?"*) and answered with cited standards.
3. **Compliance Passport Generation**: Live compilation of the printable one-page compliance dossier.
4. **Audience WhatsApp Test**: Live QR code scanned by judges/evaluators from their personal smartphones.
5. **The Deliberate Refusal**: Out-of-scope question asked (e.g., *"What is the airspeed of a swallow?"*); the assistant refuses and provides the official BIS National Toll-Free Helpline (`1800-11-4000`).
6. **Ministry Analytics View**: Real-time regulatory dashboard summarizing queries, linguistic trends, and unaddressed consumer inquiries.

##  Getting Started

### 1. Prerequisites
- **Python 3.11+**
- **Node.js 18+** & `npm`
- **Tesseract OCR** (`brew install tesseract` on macOS / `apt-get install tesseract-ocr` on Ubuntu / Installer for Windows)
- **Ollama** with the `qwen2.5:3b` model:
  ```bash
  ollama pull qwen2.5:3b
  ```

### 2. Environment Setup
Clone the repository and set up a virtual environment:
```bash
git clone https://github.com/CodingYodha/manak_mitra.git
cd manak_mitra

python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Database & Vector Index Initialization
Initialize the SQLite database with the standard schema and generate vector embeddings:
```bash
# Verify standards dataset
python scripts/verify_standards.py

# Generate vector index (creates vectors.npy and vectors_meta.json)
python api/embed_job.py
```

### 4. Running the Backend API
Start the FastAPI application:
```bash
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```
Interactive documentation is available at `http://localhost:8000/docs`.

### 5. Running the Frontend (Web Interface)
In a separate terminal:
```bash
cd web
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.

### 6. Starting WhatsApp Channel (Optional)
```bash
npm install
node whatsapp.js
```
Scan the terminal QR code using WhatsApp on your dedicated demo smartphone.

##  Evaluation & Benchmarks

Manak Mitra includes an automated evaluation harness (`eval/score.py`) executing against `eval/golden40.jsonl`. The file currently contains 26 checked-in cases; it assesses retrieval precision, citation presence, and refusal accuracy. Citation source validity is a separate verification requirement, not something this local retrieval benchmark proves.

```bash
python eval/score.py
```

### Benchmark Metrics & Targets
| Metric | Target | Description |
|---|---|---|
| **accuracy@1** | $\ge 60\%$ | Top-1 retrieved standard exactly matches ground-truth IS number |
| **accuracy@3** | $\ge 80\%$ | Target standard appears in top-3 retrieved candidates |
| **citation_presence** | $\ge 90\%$ | Non-refused answers carry at least one retrieved citation |
| **abstention_precision** | **$100\%$** | Zero hallucinated answers for out-of-domain queries |

##  Compliance & Disclaimers

1. **Authoritative Sources**: All Indian Standard numbers, titles, and Quality Control Orders are derived directly from published Ministry gazette notifications and official BIS registries.
2. **Mark Validation**: The mark verification tool performs **structural and typographical syntax analysis** (e.g. HUID format, purity codes, license patterns). Official authenticity verification remains exclusive to the government **BIS CARE** mobile application.
3. **Helpline Referral**: For unverified products or non-standard queries, users are directly referred to the Bureau of Indian Standards National Toll-Free Helpline: **`1800-11-4000`**.
